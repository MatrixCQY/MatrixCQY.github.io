This project is a **WeChat Mini Program** designed to simplify scorekeeping for social games. It provides a clean **User Interface (UI)** for players to manually input and track scores during games like Texas Hold'em or Mahjong.

Instead of complex rule engines, it focuses on providing a convenient, digital alternative to pen-and-paper scoring, ensuring real-time calculation of net wins/losses for each session.

**Tech Stack**: WeChat Mini Program (WXML, WXSS, JS), Cloud Development.
