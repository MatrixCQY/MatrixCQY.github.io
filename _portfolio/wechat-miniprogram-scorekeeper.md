This project is a **WeChat Mini Program** designed to simplify scorekeeping for social card and board games, specifically tailored for **Texas Hold'em** and **Mahjong**.

## Key Features

- **Multi-Game Support**: Customized scoring rules for different games (e.g., Mahjong fan calculations, Poker chips management).
- **Real-Time Calculation**: Automatically calculates net wins/losses for each player after every round, eliminating manual errors.
- **Historical Records**: Saves game history to the cloud, allowing users to review past results and statistics.
- **User-Friendly Interface**: Clean and intuitive UI designed for quick input during fast-paced games.

## Tech Stack

- **Frontend**: WXML, WXSS, JavaScript (WeChat Mini Program Framework)
- **Backend**: WeChat Cloud Development (Cloud Functions & Database)
- **Database**: NoSQL (Cloud Database)
